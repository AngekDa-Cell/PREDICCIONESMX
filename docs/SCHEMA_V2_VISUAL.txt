DATOS CLAVE POR TABLA
═════════════════════

🏟️  VENUE (MEJORADO)
    • altitude_m      ← altitud del estadio (¡clave en México!)
    • latitude, longitude
    • surface         ← césped natural / sintético / mixto
    • climate_zone    ← árido, templado, tropical
    • roof_type       ← abierto, retractil, fijo

👤  PLAYER (MEJORADO)
    • preferred_foot  ← zurdo/diestro
    • shirt_number
    • primary_position / secondary_position
    • date_of_birth (edad calculable)

🧠  COACH (NUEVO)
    • tactical_style    ← ofensivo, defensivo, posesión, contraataque
    • formation_preference ← 4-4-2, 4-3-3, etc.
    • years_experience

📋  FIXTURE_LINEUP (NUEVO)
    • is_starter, is_captain
    • position_group / position_detail
    • minutes_played
    • rating ← rendimiento individual
    • goals, assists, cards

🌦️  MATCH_WEATHER (NUEVO)
    • temperature_c, feels_like_c
    • humidity_pct
    • wind_kph
    • precipitation_mm
    • conditions ← "Clear", "Rain", "Cloudy"

🧠  MATCH_CONTEXT (NUEVO — "psicología")
    • is_derby, is_classic
    • home_rest_days / away_rest_days
    • home_consecutive_home / away_consecutive_away
    • psychological_pressure_home / away ← manual o calculado
    • notes_manual ← texto libre del analista

✈️  TRAVEL_LOG (NUEVO — fatiga)
    • distance_km ← calculable desde venues
    • transport_mode ← avión, autobús
    • travel_hours

📈  TEAM_FORM / PLAYER_FORM / COACH_FORM (CALCULADOS)
    • últimos 5 partidos: W/D/L, goles, rating
    • momentum_score
    • fatigue_index (jugador)
    • pressure_index (DT)
